# 📚 Online Bookstore

A full-featured **Online Bookstore** developed using **HTML, CSS, JavaScript, and PHP**.  
This project provides both **Admin** and **User** interfaces with secure login, product management, cart system, and order handling.

---

## ✨ Features

### 🔐 Authentication
- **Admin Login:** Access to the admin dashboard for managing products, users, and orders.
- **User Login:** Secure login for regular users to browse, purchase, and interact.

### 🛠 Admin Dashboard
- Manage products: Add, edit, and delete books.
- Track orders: View pending and completed orders.
- Handle user queries and messages.
- Record keeping of payments and transactions.
- Overview of total admin and user accounts.
### 🛒 User Features
- User-friendly **cart system** with add, remove, and search functionalities.
- **Intuitive search** for quick product discovery.
- **Checkout process** including delivery details.
- User messaging system for support and queries.

---

## 🛠 Built With

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure of web pages |
| **CSS3** | Styling and responsive design |
| **JavaScript** | Frontend interactivity and DOM manipulation |
| **PHP** | Backend logic, authentication, and database interaction |
| **MySQL** | Database management for users, products, and orders |
